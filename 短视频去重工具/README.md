## 通用短视频去重策略

1. **抽帧 / 插帧**：改变帧率与帧序列，破坏时序指纹。
2. **边缘混淆 / 蒙版偏移**：局部改变画面结构，降低视觉相似度。
3. **画中画 / 滤镜微扰**：在不影响观感的前提下扰动像素分布。
4. **音频替换 / 变速**：替换 BGM、微变速，规避音频指纹。
5. **批量处理**：支持一次处理几十上百条，适合矩阵号铺量。
