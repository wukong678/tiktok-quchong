# 短剧去重工具（Short Drama Dedup）

> 短剧去重 · 短剧搬运去重 · 海外短剧去重 · short drama dedup · short drama deduplication

竖屏微短剧（短剧）是出海最热门的内容形态之一，但平台对**整集重复搬运**打击严厉。短剧去重需要在「改变指纹」与「保持剧情连贯」之间取得平衡——不能像普通短视频那样大刀阔斧地扭曲画面。

## 为什么短剧去重更难

与 15 秒的短视频不同，短剧有连续的剧情。画面扰动过大，观众会丢失故事；扰动过小，平台依旧判重。本工具**按场景**处理，施加恰到好处的改变来打破指纹，同时保证整集完全可看。

## 短剧去重核心策略

1. **整集结构化处理**：按集、按场景切分，逐段做轻量指纹扰动，保证剧情不碎。
2. **画面层**：边缘混淆 + 蒙版偏移 + 局部微扭曲，幅度控制在观感可接受范围。
3. **音频层**：人声保留、BGM 替换、节奏微变速，规避音频指纹命中。
4. **字幕层**：重新生成字幕样式 / 位置，破坏字幕区域的视觉重复特征。
5. **批量铺量**：同一部短剧可批量产出多个「不重复」版本，供矩阵号分发。

## 功能亮点

- **整集感知**：处理的是整部剧，而不只是零散片段。
- **剧情安全扰动**：改变指纹的同时不破坏叙事。
- **批量变体**：一部源剧可生成多个互不相同的版本供矩阵号使用。
- **本地优先**：全部在本地电脑运行。

## 支持平台与格式

- **平台**：TikTok、Facebook、YouTube Shorts 等短剧落地平台。
- **输出**：竖屏 9:16 短剧格式，按集输出。
- **输入**：MP4 / MOV 等主流格式。

## 操作流程

1. 导入整部剧（多集）。
2. 自动按集 / 按场景切分。
3. 用剧情安全预设运行去重。
4. 逐集预览，必要时微调强度。
5. 导出并分发到矩阵号。

## 效果对比

| 维度 | 去重前 | 去重后 |
|---|---|---|
| 场景连贯 | 不变 | 保持（剧情完整） |
| 画面指纹 | 与源一致 | 按场景扰动 |
| 字幕区域 | 样式相同 | 重新生成样式/位置 |
| 分发 | 单一副本 | 多个不同版本 |

## 常见问题

**去重后剧情还讲得通吗？** 讲得通——扰动按场景以低幅度施加，剧情与对白始终连贯。

**能一次去重整部剧吗？** 能，导入全部剧集后工具会自动切分并批量处理。

**适用于海外平台吗？** 适用，针对 TikTok / Facebook / YouTube Shorts 的检测做了适配。
