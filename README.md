## 去重原理（How It Works）

不管是 TikTok 视频去重、短剧去重还是 Facebook 短剧去重，核心都是**改变视频的「内容指纹」而不破坏观感**：

1. **画面层（视觉指纹）**：边缘混淆、蒙版偏移、局部扭曲、画中画、滤镜微扰，让平台的图像相似度算法判为「不同视频」。
2. **音频层（音频指纹）**：人声分离、背景音乐替换、节奏变速，规避音频哈希匹配（TikTok / Facebook 均会比对音频指纹）。
3. **结构层（时序指纹）**：抽帧、插帧、变速、片段重排，破坏帧序列的连续性特征。
4. **元信息层**：封装层重置、关键帧重排、编码参数扰动。
