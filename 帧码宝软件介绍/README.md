# 帧码宝软件介绍（ZhenMaBao — All-in-one Video Dedup & Repurpose Workbench）

> 帧码宝 · 短视频去重 · 短剧去重 · 智能混剪 · 影视二创 · TikTok / Facebook 出海去重

**帧码宝** 是一款面向短视频创作者与短剧出海运营团队的 PC 端（Electron）工作台，把「素材采集 → 去重清洗 → 智能混剪 → 字幕配音 → 批量发布」整条链路整合到一个软件里，帮你批量产出**不被平台判定重复**的内容，规避 TikTok / Facebook 等平台的查重与限流。

## 你能做什么（核心模块）

| 模块 | 能力 | 适用场景 |
|---|---|---|
| **帧码去重** | 抽帧 / 蒙版偏移 / 边缘混淆 / 花边等多手段去重 | 短视频去重 |
| **短剧去重** | 整集结构化去重，保持剧情连贯 | 短剧去重 |
| **鲇鱼插针去重** | 针对视频号 / 出海平台的深度指纹补偿去重 | TikTok / Facebook 深度去重 |
| **智能混剪** | N×M 批量混剪、剧情脚本、错位铺量 | 短视频混剪 |
| **影视二创** | AI 解说、一键二剪、批量出片 | 影视解说 |
| **批量发布** | 多平台矩阵号一键分发 | 矩阵号铺量 |

## 功能亮点

- **一个工具，多平台**：TikTok / Facebook / 视频号 / 抖音 去重全在一处。
- **全链路**：采集 → 去重 → 混剪 → 字幕配音 → 发布，无需切换软件。
- **批量处理**：填多少出多少，矩阵号铺量无上限。
- **本地优先**：核心去重在本地完成，素材不外泄。
- **持续迭代**：紧跟各平台查重算法更新去重策略。

## 支持平台与格式

- **平台**：TikTok、Facebook（Reels/Watch）、视频号、抖音、YouTube Shorts、Instagram Reels。
- **输出**：竖屏 9:16 及常见短视频尺寸。
- **输入**：MP4 / MOV 等主流格式。

## 操作流程

1. 把源素材采集进工作台。
2. 运行去重（按平台选轻 / 标准 / 深度）。
3. 按需智能混剪，或加字幕 / TTS 配音。
4. 预览效果。
5. 批量发布到矩阵号。

## 常见问题

**真的全本地吗？** 核心去重在本地电脑完成；只有可选的发布环节才会与平台通信。

**支持哪些平台？** TikTok、Facebook、视频号、抖音、YouTube Shorts、Instagram Reels。

**深度去重有什么不同？** 「鲇鱼插针」模块对更严格的平台 / 深度去重需求施加更强的指纹补偿。
