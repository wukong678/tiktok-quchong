# 帧码宝软件介绍（ZhenMaBao — All-in-one Video Dedup & Repurpose Workbench）

> 帧码宝 · 短视频去重 · 短剧去重 · 智能混剪 · 影视二创 · TikTok / Facebook 出海去重

**帧码宝** 是一款面向短视频创作者与短剧出海运营团队的 PC 端（Electron）工作台，把「素材采集 → 去重清洗 → 智能混剪 → 字幕配音 → 批量发布」整条链路整合到一个软件里，帮你批量产出**不被平台判定重复**的内容，规避 TikTok / Facebook 等平台的查重与限流。

## 核心模块

| 模块 | 能力 | 对应关键词 |
|---|---|---|
| **帧码去重** | 抽帧 / 蒙版偏移 / 边缘混淆 / 花边等多手段去重 | 短视频去重、video fingerprint remover |
| **短剧去重** | 整集结构化去重，保持剧情连贯 | 短剧去重、short drama dedup |
| **鲇鱼插针去重** | 针对视频号 / 出海平台的深度指纹补偿去重 | TikTok 视频去重、Facebook 短剧去重 |
| **智能混剪** | N×M 批量混剪、剧情脚本、错位铺量 | 短视频混剪、overseas short drama repost |
| **影视二创** | AI 解说、一键二剪、批量出片 | 影视解说、short video repurpose |
| **批量发布** | 多平台矩阵号一键分发 | 矩阵号铺量、batch video processing |

## 为什么选帧码宝

- **一套工具覆盖 TikTok / Facebook / 视频号 / 抖音** 多平台去重
- **批量处理**：填多少出多少，矩阵号铺量无上限
- **本地处理**：核心去重在本地完成，素材不外泄
- **持续迭代**：紧跟各平台查重算法更新去重策略
